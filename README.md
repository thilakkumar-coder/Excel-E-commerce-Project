# Excel-E-commerce-Project
# 📊 Excel E-commerce Sales Dashboard

## 📌 Overview

This project is an **Excel-based E-commerce Sales Dashboard** designed to analyze sales performance, customer behavior, product performance, and revenue trends. The dashboard provides interactive visualizations and KPIs to help understand business performance.

## 📂 Dataset

The dataset contains e-commerce sales information such as:

* Order ID
* Order Date
* Customer Name
* Product Name
* Category
* Sales
* Quantity
* Profit
* Region
* Payment Mode

## 🛠️ Tools & Technologies

* **Microsoft Excel**
* Excel Formulas
* Pivot Tables
* Pivot Charts
* Slicers
* Conditional Formatting
* Data Cleaning
* Dashboard Design

## 🔄 Project Steps

1. Imported the e-commerce dataset into Excel.
2. Cleaned and formatted the raw data.
3. Used Excel formulas to create calculated fields.
4. Created Pivot Tables for data analysis.
5. Developed Pivot Charts to visualize sales performance.
6. Added slicers for interactive filtering.
7. Designed an interactive E-commerce Sales Dashboard.

## 📈 Dashboard

The dashboard provides insights into:

* Total Sales
* Total Profit
* Total Orders
* Total Quantity Sold
* Sales by Category
* Sales by Region
* Product Performance
* Monthly Sales Trends
* Profit Trends

## 🔑 Key KPIs

* **Total Sales**
* **Total Profit**
* **Total Orders**
* **Total Quantity Sold**
* **Average Order Value**
* **Profit Margin**

## 💡 Key Insights

The dashboard helps identify:

* Top-performing products and categories.
* Sales and profit trends over time.
* Regions generating higher sales.
* Customer purchasing patterns.
* Overall sales and profitability performance.

## 🎯 Objective

The objective of this project is to build an **interactive Excel dashboard** that transforms raw e-commerce data into meaningful insights and supports data-driven business decisions.

## 🚀 How to Use

1. Download the Excel dashboard from this repository.
2. Open the `.xlsx` file in Microsoft Excel.
3. Use the slicers and filters to explore different aspects of the data.
4. Analyze the KPIs, charts, and trends displayed on the dashboard.
